Lothar API v5.8 Documentation

Target Provider: TUSK (For Third-Party / ACS Middleware Integration)

Protocol Overview

  • RESTful API: OpenAPI specified HTTP interfaces (POST / GET). Request header: Content-Type: application/json
  • Asynchronous Interfaces: AsyncAPI specified WebSocket and AMQP channels.
  • Server Endpoints:
    • HTTP/HTTPS: http://192.168.1.100:7777 / https://192.168.1.100:7777
    • AMQP Server: amqp://localhost:5672 (v0-9-1, Identifier: amqp-production)
    • WebSocket Server: ws://localhost:7777 (Identifier: websocket-production)

1. Task Management (작업 관리)

1.1 Create Task (작업 생성) POST /rpc/task/create

Request Body

FieldTypeRequiredDescription
taskIdstringNoTask ID. Auto-generated when empty.
targetsarray[string]YesSequence of task target points.
configIdstringNoTask configuration ID. Default is DEF.
priorityintegerNoTask priority (larger value = higher priority).
containerIdstringNoContainer (barcode) ID.
containerTypeIdintegerNoContainer type ID (overrides config).
robotIdstringNoSpecified robot ID.
robotGroupstringNoSpecified robot group.
 
// Request Example
{ "taskId": "task001", "targets": ["A1", "B2"], "configId": "DEF", "priority": 10 }

1.2 Continue Task (작업 진행/계속) POST /rpc/task/continue

FieldTypeRequiredDescription
taskIdstringNoTask ID.
targetsarray[string]NoTarget points for appended tasks.
configIdstringNoTask configuration name for appended tasks.
targetPointstringNoName of current executing target point.

1.3 Force Complete Task (작업 강제 완료) POST /rpc/task/complete

FieldTypeRequiredDescription
taskIdstringNoTask ID.
targetPointstringNoName of current executing target point.

1.4 Cancel Task (작업 취소) POST /rpc/task/cancel

FieldTypeRequiredDescription
taskIdstringNoTask ID.
targetPointstringNoName of current executing target point.

1.5 Append Subtasks (하위 작업 추가) POST /rpc/task/append

FieldTypeRequiredDescription
taskIdstringYesTask ID.
taskTargetsarray[object]YesCollection of points and actions.
taskTargets[].actionstringYesAction: detectObject, move, pick, drop, rotate.
taskTargets[].targetstringYesTarget point name.
taskTargets[].waitbooleanNoStay and wait after action.

1.6 Modify Task Priority (작업 우선순위 변경) POST /rpc/task/priority/modify

FieldTypeRequiredDescription
taskIdstringYesTask ID.
priorityintegerYesTask priority value.

1.7 Modify Task Target Point (실행 중인 작업의 대상 지점 변경) POST /rpc/task/target/modify

FieldTypeRequiredDescription
taskIdstringYesTask ID.
newTargetstringYesName of new target point.

1.8 Query Tasks (작업 목록 및 상태 조회) POST /rpc/task/info

FieldTypeRequiredDescription
taskIdListarray[string]NoList of task IDs.
statusstringNoTask status (CREATED, EXECUTING, COMPLETED).
legoNamestringNoTask configuration name.
agvExcstringNoExecuting robot ID.
pageNum / pageSizeintegerNoPagination settings.

1.9 Query Task Configurations (설정된 작업 구성 목록 조회) GET /rpc/task/config

// Response Example
{ "code": 200, "msg": "success", "data": [{ "name": "DEF", "robotGroup": "default", "containerType": 1 }] }

1.10 Receive Executing Task Information AMQP Push (60s)

Channel: mq_executing-task | Address: queue_push_executing_task

1.11 Request Executing Task Information WebSocket

Channel: ws_executing-task | Address: /push/executing/task

Request payload: "all_task" or specific taskId.
